# 우리의 겨울 여행 — GitHub Pages

## 배포
1. `index.html`, `style.css` 파일을 GitHub Pages에서 제공하는 폴더에 업로드하세요.
2. 기존 저장소가 `/docs`에서 Pages를 제공한다면 `/docs/winter-trip/index.html`, `/docs/winter-trip/style.css`로 넣으세요.
3. 커밋 및 푸시 후 `https://사용자명.github.io/저장소명/winter-trip/`로 접속하세요.
4. 새 저장소라면 Settings → Pages → Deploy from a branch에서 main과 root를 지정하세요.

## 구성
- 반응형 단일 페이지
- 여행지 BEST 8 및 예산
- 3개 상세 일정, 방문지 지도 및 구글 지도 길찾기 링크
- 비교표 및 최종 추천

## 참고
- 이미지: Unsplash CDN의 일반 풍경 참고 이미지. 실제 해당 관광지 사진임을 보장하지 않습니다.
- 이미지와 지도는 외부 네트워크가 필요합니다.
- 지도는 첫 방문지 중심 임베드, 버튼은 Google Maps 전체 경로 길찾기입니다.
- 방문지와 비용은 여행 계획용이며 운영 시간과 교통 상황은 출발 전 확인하세요.
